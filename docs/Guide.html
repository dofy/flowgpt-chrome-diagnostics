FlowGPT Diagnostics Guide

Install the test extension in desktop Chrome and collect a report when FlowGPT or Emochi fails.

InstallRun a test

Install

  1. Unzip the download

    After unzipping, you should see this guide and a folder called flowgpt-chrome-diagnostics.

  2. Open Chrome’s Extensions page

    Type chrome://extensions in Chrome’s address bar and press Enter. Turn on Developer mode in the top-right corner.

  3. Load the extension folder

    Click Load unpacked. Select the flowgpt-chrome-diagnostics folder next to this guide and confirm. It should contain a file called manifest.json.

  4. Check that it’s installed

    Find the FlowGPT Connection Diagnostics card and check that its switch is on.

If Chrome can’t find the manifest, select the inner folder where you can see manifest.json. Keep that folder after installation.

Run a test

  1. Start recording. Open the affected FlowGPT or Emochi tab. Click the puzzle-piece icon in Chrome’s toolbar, choose FlowGPT Connection Diagnostics, and click Start recording. Start separately in each tab you want to test.
  2. Repeat what failed. Stay in the same tab and keep the same network. The small panel on the page shows the time left and the number of failed requests.
  3. Find the relevant request. Open the extension again and click Stop recording. Use Filter requests to narrow the list by request area or failure type, then select the request you want in the report.
  4. Download and share. With the error still visible, click Download ZIP. It includes the selected report, all recorded failures, and a screenshot of the visible page. Review the screenshot and send the ZIP privately to support.
